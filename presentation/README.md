# HTMX, de manière simplix !

Ici vous trouverez la présentation qui accompagne ce dépôt de code.

Elle a été faite avec [SliDesk](https://slidesk.github.io/slidesk/).

## Comment lancer la présentation ?

Une fois SliDesk, vous pouvez tout simplement, dans ce répertoire, exécuter:

```bash
$ slidesk -wvn
```

La présentation sera accessible à l'adresse http://localhost:1337/

Si vous préférez la version avec notes des présentateurs, elle sera accessible à l'adresse http://localhost:1337/notes.html
